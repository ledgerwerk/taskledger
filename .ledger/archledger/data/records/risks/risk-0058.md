The storage layout is currently v3 (`TASKLEDGER_STORAGE_LAYOUT_VERSION` in `taskledger/domain/states.py`). Migration code in `taskledger/storage/migrations.py` adds complexity. Future format changes must maintain backward compatibility or provide migration steps. Mitigation: `taskledger doctor` checks detect version mismatches; migration checks in `taskledger/services/doctor_checks/migration_checks.py` flag incompatible records.
